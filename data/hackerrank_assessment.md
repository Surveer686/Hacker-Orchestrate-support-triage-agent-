# HackerRank Assessments: Test and Assessment Issues

If a test or assessment does not start:
- Confirm the user is using a supported browser and has a stable internet connection.
- Ask whether they see an error message and what step it occurs at.
- Suggest disabling browser extensions that may block scripts.

If an assessment submission fails:
- Ask for the exact error message and timestamp.
- Confirm whether the user can reproduce the issue.
