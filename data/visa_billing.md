# Visa Billing, Charges, and Refunds

For billing questions (charged, refund, billing dispute), request clear details:
- Date and amount of the charge
- Merchant name
- Whether the transaction is pending or posted
- Whether the user recognizes the merchant

Refund notes:
- Refunds can take time to process depending on the issuer/merchant.
- If the user does not recognize the charge, treat it as potentially unauthorized and escalate.

Escalation guidance:
- If there is ambiguity about whether a charge is authorized, or the user alleges a dispute without enough detail, escalate.
